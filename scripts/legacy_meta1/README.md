# Scripts legados da Meta 1

Esta pasta preserva scripts historicos usados na primeira etapa do projeto, principalmente para preparacao inicial de dados, segmentacao e experimentos faciais preliminares.

Eles foram movidos para fora da raiz de `scripts/` para evitar confusao com a versao atual do sistema, que fica organizada em:

- `scripts/face/`
- `scripts/global/`
- `scripts/fusion/`
- `scripts/app/`
- `scripts/data/`

Use estes arquivos apenas como referencia historica ou para reproduzir partes da Meta 1. O fluxo principal atual e o sistema face + CBIR global + fusao.
